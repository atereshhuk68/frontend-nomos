# CSS 2026: Gotchas & Deep Patterns

Read when: positioning tooltips/popovers, animating dialogs, advanced theming, custom selects, auditing CSS security. Model knows basic syntax of these APIs — file covers what breaks them.

## Anchor positioning — failure modes

Syntax (`anchor-name` → `position-anchor` + `position-area` + `position-try-fallbacks: flip-block, flip-inline`) is table stakes. What bites:

- Any `position` **or `transform`** on ancestor breaks anchor link → wrap in `display: contents` or move tip so no transformed ancestor intervenes.
- Anchor must lay out BEFORE positioned element — DOM order matters; `z-index` can't fix DOM-order issues.
- Safe centering: `margin: auto` with `anchor-center`, not manual `calc()`.

## View Transitions — the close-interception gotcha

Animating dialog close needs hook *before* close:

- `'close'` fires **after** dialog left top layer — too late to animate. Intercept `'request-close'` (or `cancel` for Esc) → `preventDefault()` → `document.startViewTransition(() => dialog.close())`.
- Mutation must happen synchronously INSIDE `startViewTransition` callback — that's what gets captured.
- Top-layer elements can't pair as element-level transitions → animate on `::view-transition-old/new(root)`, `object-fit: cover`.
- Cross-document: `@view-transition { navigation: auto }` (`<meta>` deprecated); 4-second render timeout skips transition; `<link rel="expect" blocking="render">` holds paint for hero image.
- Suppress own CSS transition while VT active, else double animation.

## Style queries — string vs numeric matching

```css
/* ⚠ style(--n: 3) is STRING matching — calc is never evaluated: calc(6/2) does NOT match "3" */
@container style(--n = 3) { /* = for numeric comparison */ }
```

Typed custom properties unlock numeric form: `@property --n { syntax: '<length>'; inherits: false }` — validated, animatable, measurable. Also: `container-type` applies *style* containment, silently scopes counters.

## Layout gotchas

- `subgrid` does nothing unless item declares `grid-row: span N` (or `grid-column: span N`) — card with no span has nothing to subgrid into.
- Root scroller theft: `height: 100vh; overflow: auto` wrapper (or `overflow-x: hidden` on html/body) becomes scroller → loses scroll restoration, keyboard scroll, mobile toolbar collapse. Fix: `min-height: 100svh` + `overflow-x: clip`.
- Viewport units: default `svh`; `dvh` resizes mid-scroll as mobile toolbars animate. `field-sizing: content` auto-sizes form controls.

## Customizable select — rule-discard gotcha

Browsers not knowing `::picker()` discard **entire rule** containing `appearance: base-select` — isolate that declaration in own block. Opt behind `@media (hover: hover) and (pointer: fine)`; fallback = `appearance: none` + arrow `background-image`.

## CSS as an attack vector

User-controlled CSS can leak data from your origin:

- `@font-face` unicode-range + font-height measurement = char-by-char oracle.
- `:has(option:checked)` selectors detect form state; remote `url()` image/font requests exfiltrate it.
- Pseudo-elements can intercept clicks; CSSOM hex-escapes (`\7d\2a`) bypass naive sanitizers.

Defenses: sandbox iframes for untrusted content, block remote fetches from user CSS, allow-list characters.

## Micro-UX details

- `font-variant-numeric: tabular-nums` — counters/dashboards stop width jitter per digit.
- Concentric rounding: `outer = inner + gap` — nested radii look intentional.
- Transitions interruptible, keyframe animations not — use transitions for interaction feedback.
- Tooltip delay asymmetry: `transition-delay` only in hover-in rule so hover-out instant (rule on base selector makes exit inherit delay).

## Bidirectional text

Directionality is content-level: `dir="auto"`, `<bdi>` in markup. CSS `unicode-bidi` never fixes copy/paste or text extraction.
